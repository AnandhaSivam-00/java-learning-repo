## Conversion
- Converting the array of something to the List, use the List.of(array)
- Converting the list to array, use the list.toArray()
- char array[] to string --> use the new String(array[])


## Deleting an element
- Use the remove() method with a index / element, if if you need to pass the element means you need to type cast it.
  Example: store.remove((Character)ch);
